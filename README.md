# MAT 105: College Algebra — Exam 3 Interactive Review Hub

Welcome to the official practice and review portal for **MAT 105 (College Algebra)**. This repository hosts self-contained, interactive web review applications designed to help students master key concepts and prepare comprehensively for Exam 3.

## 📚 Exam 3 Coverage & Core Topics
This exam builds upon cumulative foundational skills while focusing heavily on advanced algebraic functions, polynomial structures, and graphical analysis:

*   **Functions & Graphs:** Analyzing graphs, piecewise-defined functions, and evaluating domain/range ($\text{Section } 2.7$).
*   **Function Operations:** Algebra of functions and composite function evaluations ($\text{Section } 2.8$).
*   **Graph Transformations:** Shifting, stretching, compressing, and reflecting parent functions ($\text{Section } 2.6$).
*   **Quadratic Functions:** Analyzing parabolas, finding vertices, and solving real-world applications ($\text{Section } 3.1$).
*   **Polynomial Foundations:** Recognizing polynomial behavior and introduction to polynomial functions ($\text{Section } 3.2$).
*   **Polynomial Division:** Long and synthetic division, plus the Remainder and Factor Theorems ($\text{Section } 3.3$).
*   **Roots & Zeros:** Finding real zeros, understanding multiplicity, and applying the Rational Zero Theorem ($\text{Section } 3.4$).
*   **Rational Functions:** Introduction to rational expressions and asymptotic behavior ($\text{Section } 3.5$).
